# 20 — Legal and licensing

> This document records the **project's policy**. It is not legal advice. Before the first
> public release, the content must be reviewed by someone with legal training (an item in
> the [TODO](../TODO.md)).

## 1. Trademarks

- Counter-Strike, Half-Life, Valve, Steam and the associated logos are trademarks of Valve
  Corporation. The project is **not affiliated** with Valve.
- The project's name, **Modern-Client.v2**, does not use Valve trademarks. "Counter-Strike"
  and "CS 1.6" appear only descriptively (the game whose gameplay is recreated).
- The project does not use Valve's logos, icons or visual identity.

## 2. Original assets

- The repository and the distributed binaries **do not contain** any Valve asset: original
  maps, models, textures, sounds, sprites, texts or configs.
- The game **works without any Valve asset** (free content and content generated by code).
  The original assets are optional: anyone with a **legitimate copy** of Counter-Strike 1.6
  can configure it locally ([ADR-0015](adr/0015-free-content-and-optional-original-assets.md)), and the engine reads the
  files directly from it ([06](06-assets-and-resources.md#23-locating-the-original-installation-optional)).
- Automated tests use **synthetic** assets created by the project (`devContent`). The parity
  suite runs on a dedicated *runner* with a licensed copy, and what is versioned is only
  **numeric** behavior data ([18](18-testing-and-quality.md#parity-tests)).
- In the future, a free asset package made by the community may allow playing without the
  original. That package needs its own license and cannot derive from Valve assets.

## 3. Clean room

The code is **written from scratch**. Rules for contributions:

| Source | Policy |
|--------|--------|
| Leaked source code of the GoldSrc engine | **Forbidden** to consult or copy. Suspicious contributions are rejected |
| Half-Life SDK | Its own restrictive license. **Do not copy** code. Behavior is reimplemented from observation and tests |
| ReHLDS, ReGameDLL_CS, Xash3D, Quake/QuakeWorld (GPL) | **Do not copy** code. Consulting them to understand behavior is allowed, but the implementation is the project's own and validated by parity tests against the original |
| Public documentation, format specifications and reverse engineering by observation | Allowed, with a reference in the code |
| Third-party libraries | Only through a declared dependency with a compatible license ([17 §5](17-build-and-tools.md#5-dependencies)) |

- Every commit has a *Signed-off-by* line (DCO), in which the contributor declares the right
  to submit the code.
- File formats (BSP, MDL, WAD, SPR) are implemented from public specifications and from
  analysis of the files themselves.

## 4. Project license

> **Decided** in [ADR-0010](adr/0010-license.md) (option A). Licenses applied in the
> [REUSE](https://reuse.software) standard: texts in `LICENSES/`, per-directory map in `REUSE.toml`.

| Component | License | Reason |
|-----------|---------|--------|
| Engine, game, server, tools and build | **GPL-3.0-or-later** with the **Rook Plugin Exception** | Ensure that engine improvements go back to the community, without tying plugins to the GPL |
| Rook toolchain (`rookc`, VM, LSP) and plugin SDK (`.rookd`, `std`) | **MIT** | Allow plugins and mods under **any license**, including closed ones |
| Documentation (`docs/`, `README.md`, `TODO.md`, `CONTRIBUTING.md`, `SECURITY.md`) | **CC BY 4.0** | Reuse with attribution |
| Game data (`data/`) | GPL-3.0-or-later, like the engine | The numeric behavior values are measured facts |

Every code file starts with the SPDX header of its license
([02 §2](02-coding-standards.md#2-file-and-module-organization)).

The plugin API boundary (bytecode + `.rookd`) is designed so that mods **are not a
derivative work** of the engine, and the **Rook Plugin Exception** (an additional permission
under section 7 of the GPL-3.0, [`LICENSES/LicenseRef-Rook-Plugin-Exception.txt`](../LICENSES/LicenseRef-Rook-Plugin-Exception.txt)) states this in the license itself. It does not cover
modified versions of the engine or native extensions. The legal review of the text is still
pending ([ADR-0010](adr/0010-license.md)).

## 5. Mods

- Mod authors hold the rights to their own mods and choose the license.
- Mods distributed through the official portal (future) have to declare a license in
  `mod.toml` and guarantee that they hold the rights to the included assets.

## 6. Privacy

- The client collects no telemetry by default. Crash reports are optional, without personal
  data.
- Servers record the IP and the `PlayerId` in logs, as the original recorded the SteamID. The
  `nextds` documentation guides operators on log retention and the applicable legislation
  (LGPD/GDPR).
- The player's identity is a local key. No central service is needed to play.
