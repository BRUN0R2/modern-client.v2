# ADR-0010 — Project license

- **Status:** Accepted (option A, with the Rook Plugin Exception). The legal review before
  the first release is still pending.
- **Date:** 2026-10-20

## Context

The project is open source and public. It needs a license that protects the engine, but
that allows plugins and mods under any license (including closed ones) and is compatible
with the dependencies ([17 §5](../17-build-and-tools.md#5-dependencies)).

## Options evaluated

| Component | Option A (strong copyleft) | Option B (weak copyleft) |
|-----------|----------------------------|--------------------------|
| Engine, game, server | GPL-3.0-or-later | MPL-2.0 |
| Rook toolchain and plugin SDK | MIT | MIT |
| Documentation | CC BY 4.0 | CC BY 4.0 |

## Decision

**Option A**, chosen by the maintainer, with an additional permission for plugins:

| Component | License | Where |
|-----------|---------|-------|
| Engine, game, dedicated server, tools, game data, build | **GPL-3.0-or-later WITH LicenseRef-Rook-Plugin-Exception** | The whole repository, except what is listed below |
| Rook toolchain (`rookc`, VM, LSP, CLI) and plugin SDK (Rook's `std` library, generated `.rookd` declarations) | **MIT** | `rook/` and the `.rookd` files generated by the build |
| Documentation | **CC BY 4.0** | `docs/`, `README.md`, `TODO.md`, `CONTRIBUTING.md`, `SECURITY.md` |

### Rook Plugin Exception

[`LICENSES/LicenseRef-Rook-Plugin-Exception.txt`](../../LICENSES/LicenseRef-Rook-Plugin-Exception.txt)
is an **additional permission under section 7 of the GPL-3.0**, in the style of compiler
runtime exceptions (GCC Runtime Library Exception, Classpath Exception):

- **Grants:** plugins and mods that interact with the engine **only through the plugin
  interface** (Rook bytecode, manifests, `.rookd` declarations, the `std` library and the
  messages exchanged through them) may use any license. They do not become a derivative work
  of the engine merely by being loaded and run by it.
- **Does not grant:** anything for modified versions of the engine, nor for native
  extensions (code that talks to the engine by other means, such as the future C++ extension
  interface), nor for engine code copied into a plugin. All of that remains under the
  GPL-3.0.
- **Modifications:** whoever modifies the engine may keep or remove the exception from their
  version, as section 7 allows.
- **Why now:** only the copyright holders can add an exception. Deciding before external
  contributions avoids having to ask every contributor for consent later.
- The identifier is `LicenseRef-` because the REUSE 3.3 specification requires that prefix
  for licenses and exceptions that are not on the SPDX list.

### Application in the [REUSE](https://reuse.software) standard

- Texts in `LICENSES/`: `GPL-3.0-or-later.txt`, `LicenseRef-Rook-Plugin-Exception.txt`,
  `MIT.txt` and `CC-BY-4.0.txt`.
- `LICENSE` at the root with the GPL text, so that GitHub and other tools recognize the main
  license.
- `REUSE.toml` with the license of each directory. `reuse lint` passes (REUSE 3.3) and runs in
  CI (the `checks` job).
- An SPDX header in every code file:

<!-- REUSE-IgnoreStart -->
```cpp
// SPDX-FileCopyrightText: 2026 Modern-Client.v2 contributors
// SPDX-License-Identifier: GPL-3.0-or-later WITH LicenseRef-Rook-Plugin-Exception
```
<!-- REUSE-IgnoreEnd -->

- Contributions come in under the license of the changed file, with *Signed-off-by* (DCO,
  [20 §3](../20-legal-and-licensing.md#3-clean-room)). The holder is "Modern-Client.v2
  contributors": each contributor keeps the copyright over what they wrote.

## Dependency compatibility

Every dependency planned in [17 §5](../17-build-and-tools.md#5-dependencies) uses permissive
licenses compatible with the GPL-3.0: Zlib, MIT, BSD-2/3-Clause, ISC, Apache-2.0 (with or
without the LLVM exception), CC0 and public domain. A new dependency has to pass this check
before it comes in ([17 §5](../17-build-and-tools.md#5-dependencies)).

## Consequences

- ✅ Forks and redistributions of the engine have to keep the code open under the GPL.
- ✅ Plugin and mod authors choose the license, guaranteed by the MIT SDK and by the exception
  written into the engine's own license, not only by the intent stated in the docs.
- ⚠️ Code from projects under licenses incompatible with the GPL-3.0 cannot be incorporated.
- ⚠️ The text of the exception (version 1.0) was drafted by the project and has not gone
  through a legal review yet. Wording adjustments may produce a version 1.1.
